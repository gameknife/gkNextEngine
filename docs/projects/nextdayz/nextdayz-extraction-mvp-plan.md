# NextDayz 持久世界与撤离 MVP

目标：让每次出击的收获与损失，都能影响下一次出击。本文是供讨论的建议基线，待讨论项尚未定案。
基于现有 [PVE 生存循环](nextdayz-productization-design.md)，复用库存、搜刮、感染者、POI 与补货机制。

## 1. 核心循环

**安全屋整理／选择携装 → 随机 POI 部署 → 搜刮与生存 → 找到信号枪 → 前往撤离点发射 → 等待直升机、登机撤离 → 物资入库／出售换黄金 → 再次出击。**

世界贯穿所有出击：撤离、死亡与重启游戏均不重置地图物资。

## 2. MVP 规则（建议）

| 模块 | 首版规则 |
| --- | --- |
| 范围 | 单人本地；一张现有地图、一个安全屋、两个固定撤离点。 |
| 安全屋 | 先以仓库与出击准备界面呈现；存取物品、选择装备、出售物资、查看黄金。仓库首版不限容量。 |
| 部署 | 可携装或空手出击；从 POI 的预设安全落点随机选择，避开建筑内部、障碍与感染者贴脸出生。基础衣物不计作携装。 |
| 世界持久化 | 保存未拾取物资、已拾取状态、地面掉落及补货剩余时间；跨次保持。沿用缓慢补货规则，重登不触发全图刷新。 |
| 信号枪 | 稀有刷新，首版作为一次性道具；仅在有效撤离点消耗并呼叫，地点无效或已有呼叫时不消耗。 |
| 直升机 | 两处可达停机坪，优先复用现有地面空地与可登顶建筑；固定航线进场、降落、限时等待、起飞，无需自由飞行模拟。 |
| 撤离判定 | 落地后到舱门交互登机，起飞完成才结算；等待与前往登机期间仍面临感染者威胁。错过航班需重新呼叫。 |
| 死亡 | 建议随身物资留为可回收掉落包，返回安全屋；仓库、黄金和地图保留。 |
| 时间 | MVP 仅在野外游玩时推进世界仿真；安全屋与离线期间暂停，不做离线补货、消耗或感染者活动。 |
| 交易 | 物品配置固定售价；出售后扣除对应物品、增加黄金。黄金用途见第 5 节。 |

信号枪稀有度、直升机到达时间和停留时间均可配置。首版不额外增加强制感染者波次，先利用现有威胁验证撤离压力。

## 3. 开发顺序与验收

| 阶段 | 开发内容 | 完成时能验证什么 |
| --- | --- | --- |
| M1 持久世界 | 世界／玩家存档，物资稳定 ID，掉落保存，补货计时恢复；拆开“新生命”和“重置世界”。 | 拾走 A、丢下 B，退出重进后 A 的状态和 B 的位置正确，补货不因重登重置。 |
| M2 安全屋与出击 | 仓库、携装选择、随机 POI 安全落点、死亡返回及掉落包。 | 连续空手／携装出击；死亡后世界和仓库保留，带入装备不会复制。 |
| M3 撤离闭环 | 信号枪道具、两个撤离点、直升机模型／进出场动画、舱门交互、状态提示与结算。 | 完成一次真实登机撤离；错误地点、重复呼叫、死亡、错过航班均正确处理。 |
| M4 黄金与交易 | 固定售价、数量选择、出售事务、黄金存档；按讨论结果接入最小购买能力。 | 撤离所得可出售，物品与黄金数量正确，重启后结果保留。 |
| M5 连续游玩验证 | 串起完整流程，覆盖跨次读档、中途退出、撤离中断和重复结算。 | 连续完成两次出击与一次死亡；同一件物资始终只有一个归属，无丢失或重复入库。 |

## 4. 实现底线

- 存档分为世界状态与玩家状态，作为同一份一致性快照提交；带装备出击、死亡掉落、撤离入库、交易都要保存完整结果。
- 物品实例属性一并保留，包括枪械装弹、数量与容器关系；地图刷新点使用稳定 ID，不将运行时节点编号用作跨次存档标识。
- 地面掉落数据独立于可回收的显示对象池，避免池容量不足时把持久物资删除。
- 加入自动保存与存档备份；读取失败要提示并保留原档，避免静默创建新世界。
- 验证重点是物资守恒和重复结算；实现时按影响范围构建，交互流程用 `gnb validate`，直升机与停机坪表现用 `gnb shot`。

MVP 暂缓：联机、可建造安全屋、仓库升级、复杂商人／动态市场、自由驾驶直升机，以及完整感染者逐个持久化。感染者沿用现有刷新机制。

## 5. 优先讨论的三个决定

| 决定 | 建议 | 影响 |
| --- | --- | --- |
| “每次进入随机 POI”如何理解？ | 按每次新出击随机；野外中途退出后原地续接，随身物资仍在地图内。撤离中的航班状态一并恢复。 | 减少退出／重登被用来换位置；若坚持每次启动都随机，需明确保留装备与航班取消规则。 |
| 死亡装备如何处理？ | 原地留下可回收掉落包。 | 支持下一次出击找回装备；仍有携装风险。也可改为死亡直接损失。 |
| 黄金首版能做什么？ | 购买少量基础食物、药品与弹药，信号枪仍依靠搜刮。 | 形成“搜刮 → 变现 → 补给 → 再出击”的长期循环；仅记录黄金可进一步缩小首版范围。 |

以上决定确认后再细化任务；完成实施后将稳定规则并入产品设计，并按文档生命周期移除此计划。
